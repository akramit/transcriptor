# Transcriptor

On a YouTube watch page, Transcriptor finds the transcript engagement panel and lets you copy the transcript or download it as a `.txt` file.

## Load unpacked

1. Open `chrome://extensions`
2. Turn on Developer mode
3. Load unpacked and select this folder (`/home/user/GitHub/transcriptor`)
4. Open a YouTube video that has a transcript
5. Use the floating **Transcriptor** card at the bottom-right of the window (Copy / Download). Optional: Include timestamps.

The extension only runs on `youtube.com/watch` pages. It works locally and does not send the transcript anywhere.
